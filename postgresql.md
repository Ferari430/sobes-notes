Почему сейчас выбирают postgres?
1. OpenSource
2. Самая популярная
3. Богатый функционал (json,jsonb, оконные функции, полнотекстовый поиск, геоданные, внетора,деревья)
4. Надежность и соответствие стандартам

СУБД - система, с  помощью которой мы управляем БД. 
БД - логическая и физическая организация данных.
Postgresql - объектно-реляционная система управления базами данных (СУБД).

Схема - логический контейнер или пространство имён внутри бд для объектов. (таблицы,представления (views), индексы, функции, типы).

Таблицы - основная структура хранения данных. 

Как postgres хранит данные?
- В файлах, файлы разбиты на блоки по 8 килобайт, блоки называбтся страницами pages
- Страница - минимальный объекм, который postgres мочет считать с диска или записать на него.
- Блок в 8 килобайт сделан для оптимизации. 

Ключи
Первичный ключ Primary Key - ключ который гарантирует уникальность строк в таблице.

Внешний ключ Foreign key - служит для ссылки на первичный ключ другой таблицы. Устанавливает связь между таблицами.
