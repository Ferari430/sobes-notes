если объявляем слайс так 
```go
	arr := []string(nil)
```
то у такого слайса под указателем на массив стоит nil. Доступные операции:
- `len(arr)` → 0
    
- `cap(arr)` → 0
    
- `append(arr, "a")` → создаёт новый массив, slice больше не nil
    
- `range arr` → 0 итераций, безопасно
    
- `arr[i]` → ❌ panic (index out of range)
    
- присваивание `arr = []string{"x"}` → создаёт slice с элементами
    
- сравнение `arr == nil` → true

	Как посчитать конечный cap? 

Помним что cap увеличивается в два раза при каждой аллокации. Имеем 1 - 2 - 4 - 8 - 16
Это те значения которые могут быть у cap. Таким образом при добавлении в цикле 10 элементов len = 10 cap = 16.
