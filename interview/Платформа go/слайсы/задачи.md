```go
func main() {
```

==Что если при добавлении элемента в слайс оригинальному слайсу хватает len для вставки элемента?== 
При передаче слайса в функцию туда передается копия слайса. Это значит что существует уже два слайса. Каждый слайс ссылается на один и тот же array. 
При добавлении ''privet''  в copySlice изменяется так же и массив array. При этом у  copySlice len=4 cap=4, в то время как у оригинального слайса slice len=3 cap=4.
В итоге при печати slice ничего не изменится в выводе. Потому что у оригинального слайса все ещё len=3, чтобы увидеть добавленное слово нужно явно указать оригинальному слайсу что теперь необходимо брать элементы из массива по 4 включительно.

```go
package main
import "fmt"
func main() {

slice := make([]string, 3, 3) // ["","",""] 3 3
fmt.Println(len(slice), cap(slice)) // 3 3
appendSlice(slice)
fmt.Println(slice) // что будет?

}

func appendSlice(slice []string) {
slice = append(slice, "privet")
fmt.Println("Внутри функции:", slice) // ["","","","privet"] 4 4
fmt.Println(len(slice), cap(slice))
}
```

==Что если при добавлении элемента в слайс оригинальному слайсу не хватает len для вставки элемента?== 
При передача слайса в функцию туда передается копия слайса. При добавлении слова в копию слайса видим что не хватает cap. Значит необходимо аллоцировать новый слайс с новыми len cap и array. В него добавится слово но изначальный слайс не изменится(останется пустым), при чем новый слайс будет указывать на новый массив! 

==Что если при передаче в функцию передаем не слайс а его срез?

```go
package main
import "fmt"

// array ["","",""] len=3 cap = 4

func main() {
slice := make([]string, 3, 4)
fmt.Println(len(slice), cap(slice))
appendSlice(slice[:2])
fmt.Println("!", slice) // ["", "", "privet"]
}

func appendSlice(slice []string) {    // copy len=2 cap=4
slice = append(slice, "privet")       // len = 3 cap =4
fmt.Println("Внутри функции:", slice) // ["", "", "privet"]
fmt.Println(len(slice), cap(slice))   //3 4
}
```
В таком случае в функцию передается копия слайса со всеми его полями(Оба слайса ссылаются на один и тот же массив из-за того что не произошло аллокации). При чем у копии мы сразу же изменяем len=2. Это значит что при добавлении элемента в копию слайса мы ставим элемент на 3 позицию. Это приводит так же и к изменению базового массива на который два слайса ссылаются. Поэтому при печати оригинального слайса мы увидим privet на 3 позиции. 

==Что будет если передадим срез но ограничем cap?== appendSlice(slice[:2:3]) **==При указании cap нельзя указывать значение выше чем у оригинального слайса иначе будет паника!==**
```go
func main() {
slice := make([]string, 3, 4)
fmt.Println(len(slice), cap(slice)) // 3 4
appendSlice(slice[:2:3]) // ---> len = 2 cap = 3
fmt.Println("!", slice) // ["","","privet"]
}

  

func appendSlice(slice []string) {
fmt.Println(len(slice), cap(slice)) // 2 3
slice = append(slice, "privet") // len = 3 cap = 3
fmt.Println("Внутри функции:", slice) // ["","","privet"]
fmt.Println(len(slice), cap(slice)) //3 3
}
```
Передаем в функцию копию среза слайса при этом изменяем len на 2 и cap на 3.  При добавлении элемента видим что есть место значит новой аллокации не будет. Соответственно меняем базовый массив. Поэтому при печати оригинального массива увидим добавленное слово (потому что его len позволяет посмотреть на участок массива который был изменен).

==Что будет если передадим срез но ограничем cap и меняем len?==appendSlice(slice[1:2:3]) ==**При указании cap нельзя указывать значение выше чем у оригинального слайса иначе будет паника!**==
```go
func main() {
slice := make([]string, 3, 4)
fmt.Println(len(slice), cap(slice)) // 3 4
appendSlice(slice[1:2:2]) // ---> len = 1 cap=len = 1
fmt.Println("!", slice) // ["","",""]
}

func appendSlice(slice []string) {
fmt.Println(len(slice), cap(slice)) // 1 1
slice = append(slice, "privet") // len = 2 cap = 2
fmt.Println("Внутри функции:", slice) // ["","privet"]
fmt.Println(len(slice), cap(slice)) //2 2
}
```

В таком случае передаем копию слайса в функцию. При этом посмотрим на структуру копии: len = 2 - 1 =1. По правилам cap не должен быть меньше len. Значит cap = len = 1. В таком случае при добавлении в копию слайса слова произойдет переаллокация слайса с увеличением его параметров. Значит оригинальный массив никак не изменится.
