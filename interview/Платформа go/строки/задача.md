

```go
func main() {
	greeting := "привет как дела"
	fmt.Println(len(greeting))
}
```
Что выведет код?
Имеем 15 символов из которых 13 это кириллица. 
Пробелы кодируются одним байтом, а кириллица - двумя байтами.
Поэтому выведет 28
```go
func main() {
	greeting := "привет как дела"
	fmt.Println(len(greeting))
	fmt.Printf("%v, %b,%c\n", greeting[1], greeting[1], greeting[1])
}
```
Что выведет код?
v - сырое значение
b - бинарное значение (0 и 1)
с - символ
