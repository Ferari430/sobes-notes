## 🎯 Ответ для собеса

> **В Go есть три способа проверить, реализует ли тип интерфейс.**
> 
> **Первый — compile-time проверка** с помощью идиомы  
> `var _ Interface = (*Type)(nil)` — она гарантирует на этапе компиляции, что тип реализует интерфейс, и является идиоматичным и предпочтительным способом.
> 
> **Второй — type assertion**, используется во время выполнения, когда у нас есть значение интерфейсного типа и нужно проверить, реализует ли оно другой интерфейс.
> 
> **Третий — type switch**, это расширение type assertion, позволяющее проверить сразу несколько типов или интерфейсов во время выполнения.

---

## 🧠 Короткая версия (если времени мало)

> **Compile-time — `var _ Interface = (*Type)(nil)`.  
> Runtime — `type assertion` и `type switch`.**
