Ниже — **та же шпаргалка по типам данных Go**, но **с указанием размера в памяти**.  
⚠️ Важно: размеры приведены для **64-битной архитектуры (amd64)** — самой распространённой. Где есть нюансы, я их отметил.

---

## 🔹 Базовые (примитивные) типы

### 🔸 Логический

```go
bool        // 1 байт
```

---

### 🔸 Целочисленные

#### Знаковые

```go
int         // 8 байт (64-bit) | 4 байта (32-bit)
int8        // 1 байт
int16       // 2 байта
int32       // 4 байта (rune)
int64       // 8 байт
```

#### Беззнаковые

```go
uint        // 8 байт (64-bit) | 4 байта (32-bit)
uint8       // 1 байт (byte)
uint16      // 2 байта
uint32      // 4 байта
uint64      // 8 байт
uintptr     // 8 байт (размер указателя)
```

---

### 🔸 Вещественные числа

```go
float32     // 4 байта
float64     // 8 байт
```

---

### 🔸 Комплексные числа

```go
complex64   // 8 байт  (2 × float32)
complex128  // 16 байт (2 × float64)
```

---

### 🔸 Строки

```go
string      // 16 байт (заголовок) + данные
```

📌 `string` — это структура:

- указатель на данные → 8 байт
    
- длина → 8 байт  
    **Сами байты строки хранятся отдельно**
    

---

## 🔹 Составные типы

### 🔸 Массив

```go
[5]int      // 5 × 8 = 40 байт
```

📌 Размер массива = `размер_типа × длина`

---

### 🔸 Срез (slice)

```go
[]int       // 24 байта + данные
```

Состоит из:

- указатель → 8 байт
    
- длина → 8 байт
    
- capacity → 8 байт
    

---

### 🔸 Map

```go
map[string]int
```

📌 Сам map — **≈ 8 байт (указатель)**  
Реальные данные выделяются динамически → размер зависит от количества элементов

---

### 🔸 Структура

```go
type User struct {
    Name string // 16 байт
    Age  int    // 8 байт
}
```

```go
sizeof(User) ≈ 24 байта (+ padding)
```

📌 Выравнивание (`padding`) может увеличить размер

---

### 🔸 Указатели

```go
*int        // 8 байт
```

---

### 🔸 Функции

```go
func(int) int   // 8 байт
```

📌 По сути — указатель на функцию

---

### 🔸 Интерфейсы

```go
interface{}     // 16 байт
```

Состоит из:

- указатель на тип → 8 байт
    
- указатель на данные → 8 байт
    

---

### 🔸 Каналы

```go
chan int        // 8 байт
```

📌 Это указатель на runtime-структуру

---

## 🔹 Специальные типы

### 🔸 alias-типы

```go
type MyInt int  // 8 байт
```

📌 Размер = размер базового типа

---

### 🔸 Встроенные псевдонимы

```go
byte = uint8   // 1 байт
rune = int32   // 4 байта
```

---

### 🔸 error

```go
error          // 16 байт
```

📌 Это интерфейс

---

### 🔸 nil

```go
nil            // 0 байт
```

---

## 🔹 Пустые типы

### 🔸 struct{}

```go
struct{}       // 0 байт
```

📌 Часто используется в каналах и map:

```go
map[string]struct{}
```

---

### 🔸 any / interface{}

```go
any            // 16 байт
```

---

## 🔹 Обобщения (Generics)

```go
func Sum[T int | float64](a, b T) T
```

📌 **Размер T определяется при компиляции**, overhead отсутствует
