Индексы в PostgreSQL - это отдельные структуры (B-Tree и тд) которые хранят "отсортированные" указатели на строки таблицы, позволяя СУДБ быстро находить нужные записи без полного сканирования таблицы.

Без индекса идет сканирование каждого поля до того как мы не найдем нужный объект.

При создании индекса происходит **полное сканирование таблицы** и построение всей индексной структуры. Это делается сразу , и когда мы обращаемся к индексу, то все данные для поиска уже готовы.

По умолчанию данные в таблице не отсортированы.

Если создаем primary key для id то БД по умолчанию создает индекс для данного столбца.

Основные способы сканирования:
1. Последовательное сканировние Seq Scan
2. Индексное сканирование [practice1](practice1.md)  [practice составной индекс](practice%20составной%20индекс.md)
3. Сканирование по битовой карте [bitmap scan](../bitmap%20scan.md)

Какие бывают индексы:
1. По одному полю[practice1](practice1.md)
2. По нескольким полям[practice составной индекс](practice%20составной%20индекс.md)
3. По выражениям (функциональный индекс)
4. Частичный индекс
5. Покрывающие индексы


Варианты поиска по индексу:
1. Поиск по ключу
2. Поиск по составному ключу: where order_id = ? and user_id = ?
3. Поиск по диапозону: where created_when > ?
4. Обработка foreign keys
