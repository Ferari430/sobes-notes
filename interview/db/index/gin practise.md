создадим таблицу со стихами и их авторами
```sql
CREATE TABLE authors_poems (  
                               id SERIAL PRIMARY KEY,  
                               author_name VARCHAR(100) NOT NULL,  
                               poem_title VARCHAR(200) NOT NULL,  
                               poem_text TEXT NOT NULL,  
                               created_at TIMESTAMP DEFAULT NOW()  
);
```

добавим индекс

```sql
CREATE INDEX idx_poem_search ON authors_poems USING gist (to_tsvector('russian', poem_text));
```

Че такое tsvector???

tsvector - разбивает строку на составляющие - i love golang ---> i,love,golang
и отрезает окончания


 gin выигрывает в точности по сравнению с gist.
 Если данные из бд читаются чаще чем пишутся то ставим gin.
 если важна скорость записи то ставим gist/ но gist менее точный в поиске.
