B-Tree - алгоритм индексирования, основанный на идее разделения данных на несколько секций, которые называются узлами дерева. Каждый узел содержит набор ключей и ссылок на дочерние узлы.

Приемущества b-tree перед hash:
1. Работает с операторами > < = >= <= BETWEEN ,IN
2. Работает с IS NULL/ IS NOT NULL
3. Работает с LIKE и ~ но только если имеет вид name LIKE 'foo%'
4. Работает с регистронезависимыми операторами поиска подстроки ILIKE и ~* но только тогда когда искомая строка начинается с символа, который одинаков и в верхнем и в нижнем регистре (например числа)
