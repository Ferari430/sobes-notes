Как уже говорилось ранее, модель данных в постгресе основана на таблицах по 1Гб в которых лежат последовательно Pages по 8кБ.

Seq scan эффективен при низкой селективности, то есть когда запрос возвращает большое количество записей из таблицы.

```plaintext
в постгресе есть что-то в роде стоимости за чтение страниц в бд. Стоимость прочтения одной таблицы равна 1 (единице). Если обернуть запрос в explain analyze то там можно увидеть стоимость которую пришлось заплатить за выборку данных из таблицы.
```
