Канал это структура которая имеем под капотом:

1. Атомарный флаг - закрыт или открыт
2. Очереди горутин на чтение и на запись
3. Мьютекс
4. Кольцевой буфер и его размер Который защищен мьютексом

Кольцевой буфер:
Есть два указателя:  один указывает на то откуда будем читать в след раз, а второй на то,  куда будем писать в след раз.

next_Pwrite = ( next_Pwrite+1) % len(ch)
[^1]: **Итерация 1:**
	
	`(0 + 1) % 3 = 1`
	
	**Итерация 2:**
	
	`(1 + 1) % 3 = 2`
	
	**Итерация 3:**
	
	`(2 + 1) % 3 = 0   ← возврат в начало кольца`
	
	**Итерация 4:**
	
	`(0 + 1) % 3 = 1`
	
	**Итерация 5:**
	
	`(1 + 1) % 3 = 2`
	
	**Итерация 6:**
	
	`(2 + 1) % 3 = 0`
