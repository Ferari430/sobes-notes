Низкоуровневый счетчик. 
Атомики используют  барьеры памяти (acquire and release), а так же  атомарные инструкции на уровне процессора, то есть такие интсрукции которые выполнятся либо полностью либо не выполнятся

Операции:
**1. Load()**  
Атомарно читает значение из переменной. Гарантирует, что получено актуальное значение без гонок.

**2. Store()**  
Атомарно записывает значение в переменную. Обеспечивает, что запись видна другим потокам сразу и без частичного состояния.

**3. Add()**  
Атомарно увеличивает (или уменьшает, если передать отрицательное число) переменную на заданное значение и возвращает результат. Используется для безопасных счетчиков.

**4. CompareAndSwap() (CAS)**  
Атомарно сравнивает текущее значение с ожидаемым и, если они совпадают, записывает новое. Возвращает `true` при успехе. Основная примитивная операция lock-free алгоритмов.

**5. Swap()**  
Атомарно заменяет текущее значение на новое и возвращает старое. Полезно для обмена значениями без гонок.
