1. Эффективность - вычисление преобразования должно быть быстрым 
2. Необратимость - алгоритм шифрования должен работать только в одну сторону
3. Детерминированнсоть - для одного и того же ключа должна возвращать одно и то же значение хэша
4. Распределенность - должна равномерно распределять данные по множеству
