  Горутина может только создать что-то, не вернуть. Чтобы горутина могла что то вернуть, нужно использовать каналы.
![Screenshot from 2025-12-08 04-55-48](../../attachments/Screenshot%20from%202025-12-08%2004-55-48.png)
Как обеспечить общение между горутинами?
1. Через канал
2. Через свою структуру с использованием мьютекса (НЕ ПОН)

```go
a := make(chan chan chan int)     
chan chan chan int  <-- это все один большой тип
```

---


```go
package main

import (
	"fmt"
	"time"
)

// Describe blocking
/*
	Канал - синхронный без буфера.
	Запускаем горутину асинк, спим 2 сек и пишем в канал.
	Важно понимать что result := <-ch - это блокирующая операция. Мы ждем пока в канал запишет
	функция async. Поэтому тут не нужна wg.
*/

func async(ch chan string) {
	time.Sleep(2 * time.Second)
	ch <- "async result"
}

func main() {
	ch := make(chan string)
	go async(ch)
	// ...
	result := <-ch
	fmt.Println(result)
}

```

```go
package main

import (
	"fmt"
)
/*
	Тут не нужна wg  потому что канал без буфера.
	В первой горутине отправили 1, и вторая горутина не сможет отправить ещё 1
	до тех пор пока мэйн горутина не прочитает из канала значение.
*/
func main() {
	ch := make(chan int)

	go func() {
		ch <- 1
	}()
	go func() {
		ch <- 1
	}()

	value := 0
	value += <-ch
	value += <-ch

	fmt.Println(value)
}

```

```go
package main

import "fmt"

/*
Канал - это указатель на структуру. Если я делаю копия канала, то фактически копирую указатель
Поэтому если запишу в оригинал значение то из копии тоже смогу прочитать.
*/
func main() {
	source := make(chan int)
	clone := source

	go func() {
		source <- 1
	}()

	fmt.Println(<-clone)
}
```
